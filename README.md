# TM Last Epoch Co-op Mod — 1.1.0-dev.32

Development release, protocol **40**. Close the game and run `update.bat` from the game folder (or pass that folder as its first argument). Both Host and Client must update. The updater verifies the exact DLL pair and keeps backups. Use **Play Offline**.

**Dev.32:** fixes Combat Assist remaining paused after toggling DPS in Mod Settings and closing F4: a hidden Settings page no longer counts as a visible panel. Adds bounded recovery for transient native reads/loading, corrects stale repeat timers after interval edits, and shows last-run/pause diagnostics in F1. Fixes Bloodrage counters **10/5 -> 10/10** in hunt notifications and quest UI. Update both DLLs; protocol40 and Internet F2 + Loot Filters policy remain unchanged. See [dev.32 changes and validation](RELEASE-1.1.0-dev32-VI.md).

**Dev.31:** removes Corruption diminishing returns from the audited EXP, native monster-gold, standard Memory Amber, LP roll, WW promotion-roll and Echo Reward Rarity paths. Existing gold /40 bonus remains, so combined gold grows faster than a straight line. Bloodrage's five earned tiers now award **2/4/6/8/10** actual initial reward charges with matching hunt displays. Fixes **x5 Shade catch-up overshoot**: only earned base/Gaze are multiplied; convergence to the native highest-C target is recalculated. Already-saved excessive Corruption is **not repaired automatically**. No native gameplay acceptance claimed; Internet rooms remain F2 + Loot Filters only. See [dev.31 changes, rates and limits](RELEASE-1.1.0-dev31-VI.md).

**Dev.30:** Glyph of Hope has a **33%** chance to remove Forging Potential cost. Glyph of Despair seal rolls are **T1 100% / T2 70% / T3 50% / T4 33%**, identical for Rare and Exalted items with T6/T7 affixes. This does not allow sealing T5–T7. Native crafting eligibility, costs, critical mechanics and saving remain in control; glyph descriptions show the custom rates. Combat Assist now uses the largest enabled target-dependent radius, capped at **30**, and rejects distant candidates before expensive native checks. The F1 slider/input/ring share that cap. Public-IP Internet rooms still keep F2 + Loot Filters only. See [dev.30 changes and validation](RELEASE-1.1.0-dev30-VI.md).

**Dev.29 — Internet inventory-only rooms:** Host/Join through a public IPv4 address and port remains supported. Rooms keep **F2 Shared Stash and shared Loot Filters**. World/enemy/combat/status/reward synchronization, remote characters/pets/VFX, Teleport, shared Monolith and Encounter are temporarily disabled. Unused native hooks are skipped entirely, and presence sends only inventory readiness/identity every 250 ms. Each player keeps their own map and native gameplay. F1 Combat Assist, DPS Tracker, density and all personal Mod Settings remain enabled. Includes the Assist/DPS performance cleanup and per-feature diagnostics. See [dev.29 changes and validation](RELEASE-1.1.0-dev29-VI.md). Dev.28 is reserved for the unfinished Encounter branch and is not included here.

**Dev.27:** speeds up Combat Assist scheduling, adds click-to-edit numeric slider values, fixes small minimap enemy dots to render at 30% size, and hides the DPS overlay after 15 seconds without damage (new damage shows it again without clearing totals). All custom Disintegrate movement, animation and related Arcane Ascendance overrides are removed; those skills use native behavior. Encounter remains paused and excluded. See [dev.27 changes and limits](RELEASE-1.1.0-dev27-VI.md).

**Dev.24:** updates F1 Combat Assist with a zero-second Hold cast mode, Low ward and an absolute Ward threshold, a detection-radius preview, and a clearer minimum-current-MP label. Small minimap enemy dots use 30% of their previous size; Tab overlay dots keep their original size. The DPS overlay stays visible, uses a transparent frame and green bars, and stacks its statistics vertically. Native gameplay/visual verification is pending. Encounter work remains paused and is excluded from this release. See [dev.24 changes and limits](RELEASE-1.1.0-dev24-VI.md).

**Dev.22:** removes all custom Disintegrate channel/movement/rotation damage patches and related Arcane Ascendance handling. Both skills return to native behavior. Update both DLLs on every peer. Encounter development is incomplete and its new native gameplay remains disabled by default. See [dev.22 changes and limits](RELEASE-1.1.0-dev22-VI.md).

**Dev.21 (historical, removed in dev.22):** removes negative Disintegrate rotation damage/ailment penalties on local offline beam instances and respects Arcane Ascendance roots, including movement destinations received before the root. Native feature observations passed; the full native gate still fails with 76 runtime errors. Physical input, full skill trees, target DPS and multiplayer remain unverified. See [dev.21 changes and limits](RELEASE-1.1.0-dev21-VI.md).

**Dev.20:** native keyboard movement now steers Disintegrate while channeling, follows game bindings, and stops movement on key release while keeping the beam active. Aim updates no longer set movement destinations. Update both DLLs on every PC. Six native keyboard directions and aim/movement checks passed in a sandbox; physical input and multiplayer remain unverified, and the full native gate still fails with 76 runtime errors. See [dev.20 changes and limits](RELEASE-1.1.0-dev20-VI.md).

**Dev.16 (historical):** adds native channel movement hooks for the local offline Disintegrate skill, intended to allow movement while channeling. Gameplay, steering, release, collision and multiplayer behavior remain unverified. Core remains dev.14. See [dev.16 changes and limits](RELEASE-1.1.0-dev16-VI.md).

**Dev.15:** removed party HP scaling, kept monster density, and reduced idle Auto Play, hidden/paused DPS, solo stash and AI/HP hook work. Restart after updating. Core remains dev.14. FPS gains and native/multiplayer regression have not been measured. See [dev.15 changes and limits](RELEASE-1.1.0-dev15-VI.md).

**Dev.14 Shared Stash update:** inventory readiness is advertised independently of borrowed Echo world readiness. Transfers now show explicit local/Host rejection reasons, with a separate status overlay and additional diagnostics. Update both DLLs on the Host and every Client. The reported case where only one of two Clients can transfer has not been reproduced or confirmed resolved. See [changes and limits](RELEASE-1.1.0-dev14-VI.md).

**F1 Combat Assist:** compact native panel with real skill/potion icons, per-slot conditions, HP/MP thresholds, enemy/rare/boss range, target selection, repeat interval and automatic potion. Dev.13 fixes mismatched icons and slider value/handle synchronization, and clarifies master and skill confirmation status. Settings follow each local character and skill identity. Press Start, then close F1/F4 to resume. Automation pauses for panels, chat, loading, death, travel or focus loss. Named stat-buff guards do not infer every aura/toggle system. See [dev.13 changes and validation limits](RELEASE-1.1.0-dev13-VI.md) and [setup and historical screenshots](RELEASE-1.1.0-dev12-VI.md).

**Room Loot Filters:** each member shares their selected filter in memory. Edits, selection changes and disabling propagate automatically, polled once per second, including across maps. Keep the local result/style when it shows an item; if it hides the item, a remote filter may show it. Ground labels attribute filters that show the item. Remote filters do not overwrite local files or character bindings. Invalid remote filters are isolated by owner. Native Match uses an ABI-aware pointer bridge instead of Harmony out-Nullable marshalling. See [filter implementation and limits](ROOM-LOOT-FILTERS-2026-10-20-VI.md).

Joining creates room membership for F2 and Loot Filters only. Each player stays in their own map and solo gameplay. Teleport and shared Echo/world participation are disabled in dev.29. Party HP scaling remains removed.

**F2 opens the independent Shared Chest**, persisted on the Host and usable across maps in the same character cycle/mode. It currently accepts eligible Gift equipment/Idols, one item per entry, with a native individual ID. It has 96 logical slots. The frontend now clones native Stash graphics and uses a new native item grid for icons and hover/tooltips. Its detached Host projection never binds personal Stash data; original controllers are stripped before activation. Cursor drop or inventory right/shift-click deposits; clicking a chest item receives it into inventory after Host/save confirmation. Pagination follows native item sizes. Shared Stash labels/help/status use English. Stash loading resolves the actual legacy/V2 panel with a bounded timeout. Item canvases have independent raycasters and native buttons keyed to Host item identity, fixing clicks passing through the chest into the world. Deposit/withdraw use durable client journals, Host reservations, save acknowledgments, operation deduplication and custody tickets. Uncertain operations stay held rather than being automatically refunded or regranted. Legacy encounter synchronization remains unsupported.

**Legacy encounter synchronization has been removed. Its replacement is not wired into gameplay yet.** This release is published at the user's request so both PCs can obtain the same cleanup build. Encounter interactions/rewards and generic map interactions are not synchronized. It does not provide shared Nemesis, Omen Window, Blood Crystal, Exiled Mage or Rift Beast gameplay. Native solo encounter behavior needs complete in-game regression testing.

Echo of a World / Shade of Orobyss now gives **x5 positive Corruption gain**, including native Gaze and catch-up bonuses. For example, +10 becomes +50. Existing Corruption is not multiplied; the native timeline cap and non-positive outcomes are preserved. Preview and completion use the same patched native calculator. The game still owns progress persistence.

Woven Potential now uses: 1 LP → 2 LP (50%) / 0 LP (50%); 2 LP → 3 LP (50%) / 1 LP (50%); 3 LP → 4 LP (25%) / 1 LP (75%). The dropped-item minimum of 1 LP does not clamp Woven failures to 0 LP. Other input LP values keep their native behavior. Crafting eligibility and use consumption remain in the native caller.

NPC movement, animation, VFX, minions, combat and party travel code is retained for future work but its native hooks and regular update paths are disabled in this release. Shared-world settings left over from older config files cannot enable it. Encounter development remains paused and its unfinished branch is excluded.

See [Vietnamese release report](RELEASE-1.1.0-dev14-VI.md) and [historical rewrite milestone](ENCOUNTER-REWRITE-VI.md).

## Build

Native game/loader references are private and not distributed. The tested runtime uses Unity 6000.4.8f1 and MelonLoader 0.7.3.

```powershell
dotnet build src/LastEpochLAN.Mod/LastEpochLAN.Mod.csproj -c Release -p:RuntimeRoot="<runtime>"
dotnet run --project tests/LastEpochLAN.SelfTest -c Release -- validation/managed-shared-chest.json
dotnet run --project tools/EncounterPatchAudit -c Release -p:RuntimeRoot="<runtime>" -- src/LastEpochLAN.Mod/bin/Release/net6.0/LastEpochLAN.dll src/LastEpochLAN.Core/bin/Release/net6.0/LastEpochLAN.Core.dll validation/patch-audit-shared-chest.json "<runtime>"
```

Native QA requires the game closed and an explicitly prepared private runtime/sandbox. Inspect `Test-NativeAdapter.ps1` first. `-NativeEncounters` is intentionally rejected; `-OmenRewards` only tests isolated native reward methods. Full campaign errors remain failures even when individual observations pass. `tests/Test-PublicUpdater.ps1` is the current updater test; `Test-Updater.ps1` is a historical test for the older release installer.

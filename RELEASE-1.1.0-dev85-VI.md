# TM Last Epoch Co-op Mod 1.1.0-dev.85

- Unleashed Power: cast Orb mỗi 2 giây khi channel Disintegrate. Đồng bộ mô tả và hai dòng Volcanic Orb Every 2 Seconds / Static Orb Every 2 Seconds.
- Flame Vent giữ chu kỳ Fireball mỗi 1 giây và node tối đa 1 điểm.
- Flame Vent dùng icon Fireball. Stardust dùng icon Meteor; Tremor và các dòng bán kính Seismic Tide dùng icon Earthquake. Bổ sung icon dự phòng cho dòng trống trên các node đã chỉnh sửa trước đó.
- Sửa tooltip mới để nhận icon override và mô tả đã thay đổi của các node liên quan.

Build Release thành công. Chưa kiểm tra hiển thị và gameplay trong game cho các thay đổi tooltip/chu kỳ trong bản này.

Đóng game và cập nhật cả hai DLL. Các máy cùng phòng nên dùng cùng phiên bản.
